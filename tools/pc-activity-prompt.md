# Кто включал компьютер

Раздел: Промпты. Добавлен в базу: 2026-11-08.
Автор: privatekey7.

## Что делает

Промпт для Claude Code: по журналу событий Windows за неделю таблица по дням, когда комп включали, выключали, будили и кто входил, плюс неудачные попытки входа.

## Команды и шаги

```
Покажи, когда включали этот компьютер за последние 7 дней и кто в него входил. Используй журнал событий Windows (Get-WinEvent), только чтение, ничего не меняй. Журнал «Система»: 6005 включение и 6006 выключение (источник EventLog), 42 уход в сон (Kernel-Power), 1 выход из сна только от источника Microsoft-Windows-Power-Troubleshooter, 7001 и 7002 вход и выход (Winlogon). Событие 1 от других источников (Kernel-General это смена системного времени) не считай пробуждением. Если у тебя есть права администратора, загляни в журнал «Безопасность»: 4624 входы и 4625 неудачные попытки входа, с именем учётной записи и типом входа. Сведи всё в одну таблицу по дням и отдельно отметь, что было ночью или пока я, судя по всему, не работал.
```

Запусти Claude Code в PowerShell. Для неудачных попыток входа (журнал «Безопасность») открой PowerShell от имени администратора.

## Учти

Событие 1 бывает от разных источников: пробуждение только Power-Troubleshooter, остальное обычно сверка часов и не тревога.
