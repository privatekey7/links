Ускорить старый Xiaomi

Добавлен 2026-11-05 · автор privatekey7

Что делает

Промпт для Claude Code: по Wi-Fi, без рута и без удаления отключает рекламу, аналитику и фоновые сервисы прошивки, чтобы старый Xiaomi перестал тормозить. Всё возвращается одной командой.

Команды и шаги

Подключись к моему Xiaomi по ADB через Wi-Fi (отладку по Wi-Fi я включил, адрес и код сопряжения дам). Сначала сохрани список системных пакетов и замер памяти (dumpsys meminfo). Потом отключи через pm disable-user --user 0, без root и без удаления: аналитику и рекламу MIUI, ленту, магазины и браузер Xiaomi, предустановки Facebook и Amazon, фоновые сервисы Xiaomi, плееры и FM-радио, ненужные приложения Google. Не трогай рабочий стол, безопасность, Mi-аккаунт, звонилку, SMS, контакты, Play и клавиатуру, пока нет замены. Перед каждым пакетом говори, что это. Сохрани список в файл вместе с командой отката (pm enable) и в конце снова замерь память.

На телефоне: Настройки → О телефоне → 7 раз нажать на «Версия MIUI», затем Расширенные настройки → Для разработчиков → Отладка по Wi-Fi. Компьютер и телефон в одной сети. На Redmi 9A (2 ГБ) занятая память упала с 1,64 до 1,37 ГБ, загрузка 32-46 с.

Учти

Список проверен на Redmi 9A с MIUI Global 12.5.7 (Android 11): на другой модели агент сверяет пакеты с телефоном. Обновление MIUI (com.android.updater) так отключить не выходит.
