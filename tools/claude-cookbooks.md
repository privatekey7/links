# Claude Cookbooks

Раздел: Разное. Добавлен в базу: 2026-10-27.
Автор: Anthropic.

## Что делает

Готовые ноутбуки: агенты с инструментами, RAG, картинки, сабагенты, кэш.

## Команды и шаги

```
git clone https://github.com/anthropics/claude-cookbooks
```

Открывай нужный ноутбук в Jupyter или VS Code и вставь свой ключ API.

## Учти

Нужен ключ Claude API, запросы через него платные.
