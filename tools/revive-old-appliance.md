# Оживить брошенную умную технику

Раздел: Промпты. Добавлен в базу: 2026-11-05.
Автор: McArhony (драйвер), privatekey7 (промпт).

## Что делает

Промпт для Claude Code: выяснить, как старая умная техника общается по домашней сети, и вернуть управление без облака производителя. Рядом готовый драйвер SmartThings для стиралок Samsung Smart Control.

## Команды и шаги

```
Производитель закрыл приложение для моей техники: [что, модель]. Помоги вернуть управление без перепрошивки и без вскрытия. Сначала найди её в домашней сети, посмотри открытые порты и как она отвечает, поищи на GitHub проекты для похожих моделей. Каждую проверку делай только на чтение. Потом сделай локальное управление (SmartThings Edge или Home Assistant) без облака производителя. Ничего не отправляй на технику, пока я не подтвержу.
```

Для стиралок Samsung Smart Control примерно 2013–2015 годов (порт 2878, например WW10H9400EW) драйвер уже готов: репо McArhony, руководство docs/smartthings.md. Нужен хаб SmartThings: Hub v2 или v3, Aeotec или свежий телевизор Samsung со встроенным хабом.

## Учти

Неофициально, проверено на одной модели (WW10H9400EW). Не держи кнопку Smart Control до «AP»: стиралка уйдёт из Wi-Fi. У старой техники нет обновлений безопасности.
