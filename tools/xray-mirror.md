# X-Ray Mirror: «рентген» черепа и мозга по веб-камере

Раздел: Разное. Добавлен в базу: 2026-11-19.
Автор: Хашем Аль-Гаили (Hashem Al-Ghaili), собрано с Claude Fable 5.2.

## Что делает

Страница в браузере: веб-камера следит за лицом и руками, а сверху ложатся 3D-череп, мозг, мышцы, глаза и кости кисти. Челюсть открывается вместе с ртом. Слои включаются по одному, есть вид «рентген» или «сплошной», половина лица изнутри и подписи. Видео не уходит с компьютера.

## Команды и шаги

```
Открой https://masterofvfx2070.github.io/xray-mirror/, нажми «Start camera» и разреши камеру
Совет автора: вид «Solid», ползунок «Real me showing through» на половину, затем «Overall size», пока череп не встанет по лицу
```

Нужен компьютер с веб-камерой и интернет (библиотеки грузятся из сети). Бесплатно, без регистрации.

## Учти

Это не рентген: анатомия одного взрослого из открытой базы BodyParts3D, растянутая под твою голову. Для обучения и развлечения, не для диагноза.
