# Projectivy Launcher

Раздел: Телевизор. Добавлен в базу: 2026-10-28.
Автор: Spocky.

## Что делает

Лаунчер для Android TV без рекламы: ставится из Google Play и заменяет главный экран.

## Команды и шаги

```
Google Play на телевизоре → Projectivy Launcher → Установить
```

Без агента и без отладки: путь проще, если нужен только чистый экран.
