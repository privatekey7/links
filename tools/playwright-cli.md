# Playwright CLI

Раздел: Агенты. Добавлен в базу: 2026-10-25.
Автор: Microsoft.

## Что делает

Агент сам открывает браузер, жмёт кнопки и снимает скриншоты.

## Команды и шаги

```
npm install -g @playwright/cli@latest
playwright-cli install --skills
```

## Учти

Проверит только то, что ты попросил.
