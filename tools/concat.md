# Concat

Раздел: Разное. Добавлен в базу: 2026-10-29.
Автор: jub0t.

## Что делает

Бесплатный видеоредактор вместо CapCut: сам делает субтитры, озвучивает текст, вырезает фон. Без водяного знака, аккаунта и интернета.

## Команды и шаги

```
https://concat.standalones.org
xattr -dr com.apple.quarantine /Applications/Concat.app
```

Скачай установщик на сайте: есть Windows, macOS, Linux и Android. Windows сначала испугается: нажми «Подробнее», потом «Выполнить в любом случае». Вторая команда только для Mac, если он не открывает программу. Модели для субтитров и озвучки скачиваются один раз в настройках.

## Учти

Это бета, у блогера она вылетала. Озвучка и клон голоса только на английском, у вырезанного фона светится ореол. Русские субтитры никто не проверял.
