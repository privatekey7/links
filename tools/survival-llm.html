Survival LLM

Добавлен 2026-11-03 · автор anonnerdfrenzy

Что делает

Бесплатный ИИ-справочник для чрезвычайных ситуаций, работает без интернета: ~1,5 млн статей по медицине, выживанию и ремонту, ответ со ссылкой на абзац источника.

Команды и шаги

https://github.com/anonnerdfrenzy/survival-llm/releases/latest

Ставь, пока есть интернет: программа сама подберёт модель под память. 16–31 ГБ: Granite 4.2 8B (6 ГБ); Mac 32–96 ГБ: Qwen3.8 27B (18 ГБ); Windows от 32 ГБ: Nemotron 3.5 Lightning (25 ГБ). Библиотека 1,3 ГБ (малая) или ~9 ГБ (полная). Mac на Apple Silicon с macOS 14+, Windows 10/11.

Учти

Библиотека почти вся на английском. На 8 ГБ памяти только поиск по библиотеке, без ответов нейросети. Маленькие модели ошибаются чаще: проверяй источник.
