# opusplan

Раздел: Модели. Добавлен в базу: 2026-11-12.
Автор: Anthropic.

## Что делает

Режим Claude Code: в режиме плана думает Opus и пишет пошаговый план, а код по утверждённому плану пишет Sonnet, вдвое дешевле.

## Команды и шаги

```
/model opusplan
```

## Учти

Пишется слитно, без дефиса.
