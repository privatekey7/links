Что делает

Физик отдал Claude свою статью 2007 года: тот вывел все расчёты заново и нашёл ошибку в знаке. В репозитории выкладки, код проверки и список найденного.

Команды и шаги

Work sequentially, one step at a time. Do not split the task into parallel parts or subagents.
git clone https://github.com/eokahya/claude-audits-quantum-gravity.git

Первая строка: совет автора для промпта к большой проверке, чтобы ошибка не расползлась по параллельным агентам. Вторая скачивает репозиторий, проверки запускает python3 code/run_all.py.

Учти

Десять часов работы растянулись на три дня. Какие места ещё должен проверить живой эксперт, автор перечислил в README.
