# treadmill-home

Раздел: Разное. Добавлен в базу: 2026-11-11.
Автор: Crawler757.

## Что делает

Своё меню для экрана беговой дорожки NordicTrack: Netflix, Crunchyroll, браузер, скорость и наклон на отдельной панели, без входа в iFIT и рекламы. Собрано с Claude Code.

## Команды и шаги

```
Вот проект https://github.com/Crawler757/treadmill-home. У меня беговая дорожка [модель] с экраном на Android. Прочитай README и раздел про откат, скажи, подходит ли моя модель и что может сломаться. Ничего не запускай на дорожке без моего «да», первым шагом сделай бэкап.
```

Нужен компьютер в той же Wi-Fi сети, adb и Android SDK. Проверено на NordicTrack Commercial 2250.

## Учти

Сброс к заводским настройкам стирает меню, гарантия может слететь.
