# Knowledge Work Plugins

Раздел: Скиллы. Добавлен в базу: 2026-10-25.
Автор: Anthropic.

## Что делает

Плагины-специалисты: продажи, маркетинг, финансы, юрист, данные и ещё 12 ролей.

## Команды и шаги

```
claude plugin marketplace add anthropics/knowledge-work-plugins
claude plugin install sales@knowledge-work-plugins
```

Вместо sales подставь нужный: marketing, finance, legal, data…

## Учти

Из коробки это заготовки: свои сервисы и правила впиши сам.
