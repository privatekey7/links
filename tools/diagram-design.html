diagram-design

Добавлен 2026-10-28 · автор Cathryn Lavery

Что делает

Скилл для ИИ-агента: просишь обычными словами, он рисует схему одним html-файлом в стиле твоего сайта. Больше 40 видов схем.

Команды и шаги

npx skills add cathrynlavery/diagram-design
/plugin marketplace add cathrynlavery/diagram-design
/plugin install diagram-design@diagram-design

Первая команда для любого агента, две другие для Claude Code. Чтобы взять стиль с сайта, напиши агенту: onboard diagram-design to https://твой-сайт.

Учти

Схему не правят руками, как текст: хочешь изменить, просишь агента ещё раз, и он тратит токены. Для документации в Git автор сама советует Mermaid.
