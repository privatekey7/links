# Supabase MCP

Раздел: MCP. Добавлен в базу: 2026-10-25.
Автор: Supabase.

## Что делает

База, миграции и логи прямо из чата с агентом.

## Команды и шаги

```
claude mcp add --scope project --transport http supabase "https://mcp.supabase.com/mcp"
```

Потом в /mcp нажать Authenticate.

## Учти

Рабочую базу подключай только с read_only=true.
