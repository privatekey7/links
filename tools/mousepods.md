# MousePods

Раздел: Разное. Добавлен в базу: 2026-11-12.
Автор: starman-tech.

## Что делает

Превращает AirPods 3 и AirPods Pro в мышку: курсор, камера в играх и видео 360° на YouTube двигаются поворотом головы.

## Команды и шаги

```
git clone https://github.com/starman-tech/mousepods
```

Есть установщик Flatpak и расширение для Chrome (видео 360°).

## Учти

Пока только Linux.
