Pinky: агент управляет телефоном

Добавлен 2026-11-23 · автор DIYgod (автор RSSHub)

Что делает

Пускает агента в смартфон: открыть мессенджер, напечатать «опаздываю», полистать приложения. Опасные шаги ждут твоего клика, сам себе разрешить агент не может. Бесплатно и без аккаунта, Mac, Windows, Linux.

Команды и шаги

https://github.com/DIYgod/pinky/releases/latest
claude mcp add --scope user pinky -- pinkyctl mcp

Android: 7 раз тапнуть «Номер сборки», включить «Отладка по USB», подключить кабелем. iPhone (iOS 17.4+): кабель, «Доверять», «Режим разработчика». Что ждёт клика: Settings › Safety, по умолчанию платежи, добавь туда отправку сообщений. Без телефона: Add phone › Virtual phone.
