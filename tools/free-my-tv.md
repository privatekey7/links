# Free My TV

Раздел: Телевизор. Добавлен в базу: 2026-10-30.
Автор: simbasjungles (Simba).

## Что делает

Бесплатное приложение с быстрым главным экраном без рекламы: твои приложения, погода и подборки. Работает на Google TV, LG и Samsung, ставится с компьютера по Wi-Fi.

## Команды и шаги

```
LG: git clone https://github.com/simbasjungles/free-my-tv && cd free-my-tv && python3 webos/build.py
LG: python3 webos/install.py <IP телевизора>
Samsung: на пульте в «Приложениях» набери 12345, включи Developer mode, затем TizenBrew Installer → simbasjungles/free-my-tv
Для агента: Install Free My TV (github.com/simbasjungles/free-my-tv) on my LG TV at <IP>. I live in <город>.
```

На LG сначала поставь из магазина приложение Developer Mode и войди бесплатным аккаунтом разработчика. Агент сам соберёт и поставит, пароль с экрана вводишь сам.

## Учти

На LG и Samsung это приложение поверх: родной экран с рекламой и слежка остаются. Слежку выключай в настройках сам: у LG это Live Plus, у Samsung Viewing Information Services. Режим разработчика LG слетает примерно через 40 дней, жми Extend.
