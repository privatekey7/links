ZigZag: программа для вышивальной машинки

Добавлен 2026-11-17 · автор Kathy Korevec (simpsoka)

Что делает

Открытая программа для Windows и macOS (Apache 2.0): грузишь картинку или SVG, выбираешь тип стежка и смотришь предпросмотр. Отправляет дизайн на Brother Skitch PP1 по Bluetooth, для остальных машинок сохраняет файл под флешку. Есть встроенный MCP-сервер для ИИ-агента.

Команды и шаги

Скачать: https://zigzag.diy
Skitch PP1: закрой приложение Artspira, включи Bluetooth и отправь дизайн из ZigZag
Другие машинки: экспорт в PES, DST, EXP, JEF или VP3 и перенос на флешку

README советует не обновлять прошивку Skitch. Протокол Bluetooth автор сверяла с открытым проектом Respira.

Учти

Это неофициальная программа, не от Brother. Подписка Artspira+ для работы Skitch не обязательна: бесплатное приложение работает, но функций меньше (до 20 дизайнов, без ИИ-фильтров и оцифровки).
