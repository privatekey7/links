# Списки CleanYourTV по моделям

Раздел: Телевизор. Добавлен в базу: 2026-10-28.
Автор: Gathin и сообщество.

## Что делает

Для 293 моделей телевизоров список того, что можно выключить, с пояснением к каждому пакету.

## Команды и шаги

```
TV_HOST=<ip телевизора> tools/disable.sh examples/<модель>/debloat.txt
TV_HOST=<ip телевизора> tools/restore.sh examples/<модель>/debloat.txt
```

Найди папку своей модели, закомментируй строки, которые хочешь оставить.

## Учти

На Sber Salute TV отладку включали через заводское меню, это рискованно.
