ex-USSR Kinship Research

Добавлен 2026-11-02 · автор Денис Ширяев

Что делает

Скилл для Claude Code и Codex: ищет предков по архивам 15 бывших республик СССР, у каждого факта статус доказательства, в конце отчёт по каждой родственной связи.

Команды и шаги

npx skills add https://github.com/DenisSergeevitch/ex-ussr-kinship-research
Моего прадеда сослали в Казахстан в 1930-е годы. Помоги найти его родителей в церковных книгах.

Поставь скилл и напиши агенту, что знаешь о человеке: имя, годы, место. Вторая строка: пример запроса из README. Скриптам нужен Python 3.

Учти

На сайты архивов входишь сам, агент только подсказывает, что нажать. Живых людей искать отказывается. Когда открытые источники кончаются, готовит вопросы для родственников и запросы в архивы.
