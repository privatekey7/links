Кухонный экран из старой колонки

Добавлен 2026-11-09 · автор privatekey7

Что делает

Промпт для Claude Code: находит прошивку для старой колонки с экраном или планшета и собирает дашборд Home Assistant, где панели меняются сами.

Команды и шаги

Хочу превратить старое устройство с экраном в кухонный экран для Home Assistant. Устройство: [модель колонки или планшета]. 1) Найди проверенную инструкцию по прошивке именно этой модели, перескажи шаги и что может её окирпичить. Ничего не запускай на устройстве, пока я не скажу «да». 2) Экран только показывает страницу в режиме киоска, вся логика в Home Assistant на [Raspberry Pi или сервере]. 3) Хочу видеть: [транспорт до работы, цена электричества, погода, кто когда будет дома, рецепты, музыка]. Скажи, какие данные уже есть в Home Assistant, а для каких нужны внешние API и ключи. 4) Собери страницу дашборда, где нужная панель появляется сама по времени и ситуации, покажи скриншот и остановись на мою проверку.

Нужен работающий Home Assistant и Claude Code на компьютере или Raspberry Pi в той же сети, что и экран.

Учти

После прошивки голосового помощника на колонке нет.
