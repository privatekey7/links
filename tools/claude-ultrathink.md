# ultrathink

Раздел: Модели. Добавлен в базу: 2026-11-12.
Автор: Anthropic.

## Что делает

Слово в любом месте промпта: этот один ответ Claude Code думает на xhigh, со следующего сообщения effort как был. В терминале слово подсвечивается радугой.

## Команды и шаги

```
почини баг со скроллом списка ultrathink
```

Для одного трудного бага, когда не хочется переключать /effort и потом забыть вернуть.
