# Anatomy

Раздел: Скиллы. Добавлен в базу: 2026-10-28.
Автор: Ryan (@wheresryan22).

## Что делает

Скилл для Claude Code: объясняет идею, собирая живую машину, которую можно крутить и разбирать. Больше сотни готовых машин лежат в галерее бесплатно.

## Команды и шаги

```
npx skills add wheresryan22/anatomy -g -a claude-code
/anatomy объясни, как работает <что угодно>, interactive
https://skills.wheresryan.sh/anatomy
```

Сначала загляни в галерею, там готовые машины без установки. Свою заказываешь одной строкой в Claude Code, работает и в Codex.

## Учти

Долго и дорого по лимитам: часы Claude собирал почти два часа, турбину 14 часов, автор пишет про сборки дольше двух суток. Первую фигуру считай черновиком.
