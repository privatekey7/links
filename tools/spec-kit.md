# Spec Kit

Раздел: Агенты. Добавлен в базу: 2026-10-26.
Автор: GitHub.

## Что делает

Сначала спецификация, потом план, задачи и код по шагам.

## Команды и шаги

```
uv tool install specify-cli
specify init my-project --integration claude
```

Дальше в чате Claude по очереди: /speckit-constitution, /speckit-specify, /speckit-plan, /speckit-tasks, /speckit-implement.

## Учти

Нужны Python 3.11+ и uv. Проверяй результат каждого шага сам.
