# ECC

Раздел: Агенты. Добавлен в базу: 2026-10-27.

## Что делает

311 скиллов, 71 агент, хуки, память и проверка безопасности для Claude Code.

## Команды и шаги

```
/plugin marketplace add https://github.com/affaan-m/ECC
/plugin install ecc@ecc
```

Или мастером установки: npx ecc-universal@2.2.3 setup. Выбери один способ, не оба.

## Учти

Ставь только из официального репозитория: в копиях бывают вирусы.
