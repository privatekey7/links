# Правила для чистки магнитолы

Раздел: Промпты. Добавлен в базу: 2026-11-01.
Автор: u/Crunchy-Nut1 (Reddit).

## Что делает

Шесть правил, которые автор дал Claude Code перед чисткой китайской магнитолы на Android по Wi-Fi: бэкап, ждать ОК, только отключать, не трогать камеру, руль, CarPlay и радио.

## Команды и шаги

```
backup everything before changing anything
show me the list and wait for my OK
disable apps, don't uninstall them
don't touch CarPlay, Android Auto, the radio, the backup camera or the steering wheel buttons
never sign into anything for me
only install apps from their official GitHub releases
Перед любой правкой сделай бэкап всего
Покажи список и жди моего ОК
Приложения только отключай, не удаляй
Не трогай CarPlay, Android Auto, радио, камеру заднего хода и кнопки на руле
Никуда не входи за меня
Ставь приложения только из официальных релизов на GitHub
```

Вставь правила в начало разговора с агентом, прежде чем просить что-то чистить. Первая строка оригинал на английском, вторая перевод.

## Учти

Повторяешь на свой страх: ошибка в системе магнитолы может лишить камеры заднего хода. Автор работал по Wi-Fi через отладку Android.
