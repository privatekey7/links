# CallMe

Раздел: Агенты. Добавлен в базу: 2026-11-09.
Автор: ZeframLou.

## Что делает

Плагин для Claude Code: звонит тебе на телефон или часы, когда задача готова, застряла или нужен твой выбор, и слушает ответ голосом.

## Команды и шаги

```
/plugin marketplace add ZeframLou/call-me
/plugin install callme@callme
```

Нужны номер у Telnyx или Twilio, ключ OpenAI для распознавания речи и бесплатный ngrok. Переменные CALLME_… пропиши в ~/.claude/settings.json.

## Учти

Звонки и распознавание речи платные у провайдеров, сам плагин бесплатный.
