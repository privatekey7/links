# SkillUI

Раздел: Дизайн. Добавлен в базу: 2026-10-25.
Автор: Amaan Khan.

## Что делает

Вытаскивает цвета, шрифты и отступы любого сайта в файл для агента.

## Команды и шаги

```
npm install -g skillui
skillui --url https://linear.app
```

## Учти

Без ИИ и ключей, но последний коммит был в мае.
