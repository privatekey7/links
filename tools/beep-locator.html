Beep Locator: найти, что пищит в доме

Добавлен 2026-11-15 · автор Саймон Уиллисон (simonw)

Что делает

Программа превращает телефоны, планшеты и ноутбуки в комнате в решётку микрофонов. Устройства слушают писк, сервер по разнице времени прихода звука считает, где источник, и рисует круг на карте. У автора нашла старый датчик угарного газа с точностью около 40 см.

Команды и шаги

git clone https://github.com/simonw/beep-locator && cd beep-locator && uv run beep-locator serve --tunnel
Напиши файл problem.md с описанием задачи. В комнате что-то пищит, и я не могу найти что. Хочу расставить по комнате несколько устройств (ноутбуки, телефоны, iPad), чтобы все одновременно слушали и помогали вычислить, откуда идёт писк.

Нужны менеджер Python uv и cloudflared: браузеру телефона для микрофона нужен https, поэтому туннель. Устройств лучше три и больше. Вторая команда это перевод первого запроса автора Claude Code.
