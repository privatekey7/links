# Запрет на удаление: как уберечь файлы от ИИ-агента

Раздел: Безопасность. Добавлен в базу: 2026-11-20.
Автор: Anthropic (документация), совет с копиями из треда HN.

## Что делает

Профессор Чикагского университета дал Claude поправить номера страниц и ушёл обедать. Вернулся: силлабус и конспекты за год удалены, спасла история версий Dropbox. Четыре защиты: запрет rm в настройках, хук, который блокирует удаление, отдельная папка с копиями или git, режим с проверкой действий.

## Команды и шаги

```
{"permissions": {"deny": ["Bash(rm *)", "Bash(rmdir *)"]}}
Хук PreToolUse: скрипт выходит с кодом 2 и блокирует действие. Пример protect-files.sh в https://code.claude.com/docs/en/hooks-guide (раздел «Block edits to protected files»)
Перед любым удалением, перезаписью или правкой файла сделай копию рядом с номером версии.
Рабочая папка под git или в облаке с историей версий (Dropbox, Google Drive)
Cowork: отдельная рабочая папка, при запросе на удаление не жми «Allow» не глядя
```

Первое вставь в .claude/settings.json: ловит обычный rm, но не bash -c 'rm …'. Третье строка для CLAUDE.md: это просьба, а не запрет. /rewind не вернёт файл, удалённый командой. Самое надёжное из простого: копия папки или git до запуска агента.
