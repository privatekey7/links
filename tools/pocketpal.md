# PocketPal AI

Раздел: Разное. Добавлен в базу: 2026-11-13.
Автор: a-ghorbani.

## Что делает

Бесплатное приложение для iPhone и Android: скачиваешь модель один раз, и дальше нейросеть работает прямо в телефоне, без интернета. Переписка никуда не уходит.

## Команды и шаги

```
Qwen3.5-9B-abliterated — свежий флагман
Qwen3.5-4B-abliterated — средний телефон
Qwen3.5-2B-abliterated — старый телефон
```

В приложении: «Модели» → «+» → «Скачать с Hugging Face», в поиск вставить название модели. Без слова abliterated скачается обычная версия с фильтрами.

## Учти

Модель на 9B весит 4–6 ГБ: качать по Wi-Fi и проверить свободное место.
