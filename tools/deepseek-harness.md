# DeepSeek Harness

Раздел: Агенты. Добавлен в базу: 2026-10-30.
Автор: DeepSeek AI.

## Что делает

Свой агент для кода от DeepSeek с открытым кодом: открывается чатом в браузере, читает файлы, правит код и запускает команды.

## Команды и шаги

```
npx @deepseek-ai/dsh web
ollama launch dsh --model qwen3.8
```

Нужен Node.js версии 24.9 или новее. После запуска открой Settings → Models и вставь ключ DeepSeek, а потом выбери папку проекта. Вторая команда запускает его на модели у тебя на компе через Ollama.

## Учти

Это ранняя версия: проверку безопасности она не проходила, так что запускай на виртуалке и держи бэкапы. Программа бесплатная, а за ответы модели платишь по токенам.
