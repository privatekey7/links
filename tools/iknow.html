iKnow: что о тебе знает Mac

Добавлен 2026-11-11 · автор 8rank

Что делает

Локальная страница, которая открывает скрытый граф связей macOS: кого Mac считает мамой, партнёром, коллегой и с какой уверенностью. Только читает, ничего не меняет и никуда не отправляет.

Команды и шаги

git clone https://github.com/8rank/iKnow && cd iKnow && python3 server.py
Открой папку iKnow и прочитай MANUAL_FOR_YOUR_AGENT.md. Запусти iKnow на моём Mac по этой инструкции, открой страницу и расскажи по-русски, кого система записала мне в родственники и партнёры и с какой уверенностью. Ничего не меняй и никуда не отправляй.

Нужен Python 3 и полный доступ к диску для Терминала (Настройки → Конфиденциальность → Полный доступ к диску).

Учти

Проверено на macOS 26.6–27.0, на других версиях часть страниц может быть пустой.
