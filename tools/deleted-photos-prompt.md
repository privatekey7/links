# Удалённые фото в телефоне

Раздел: Безопасность. Добавлен в базу: 2026-11-09.
Автор: privatekey7.

## Что делает

Промпт для Claude Code: через adb находит на Android скрытые папки с миниатюрами удалённых фото, считает, сколько их осталось, и показывает приложения с доступом ко всем файлам.

## Команды и шаги

```
Проверь мой Android-телефон на остатки удалённых фото. Телефон подключён по USB с включённой отладкой, работай через adb, только чтение: ничего не удаляй и не копируй на компьютер без моего «да». 1) Найди скрытые папки с миниатюрами: DCIM/.thumbnails, Pictures/.thumbnails и похожие в общем хранилище. Посчитай файлы и объём, покажи самую старую и самую новую дату. 2) Сравни с тем, что сейчас есть в галерее (MediaStore), и скажи, сколько миниатюр осталось от фото, которых в галерее уже нет. 3) Покажи приложения с разрешением «Доступ ко всем файлам» (MANAGE_EXTERNAL_STORAGE) и отметь те, кому оно явно не нужно. 4) Дай команды, чтобы очистить папки миниатюр, и жди моего подтверждения.
```

На телефоне включи «Для разработчиков» → «Отладка по USB», подключи кабелем к компьютеру, поставь Android Platform Tools (adb) и запусти Claude Code. Без компьютера: файловый менеджер → показать скрытые файлы → DCIM/.thumbnails.

## Учти

Миниатюры — уменьшенные копии. Для фото, которые остались в галерее, она создаст их заново.
