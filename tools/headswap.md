# Headswap: Android Auto, Яндекс Навигатор и Алиса на магнитоле с Baidu CarLife

Раздел: Разное. Добавлен в базу: 2026-11-20.
Автор: Егор (YegorkaPomidorka), сделал с Claude Code.

## Что делает

Приложение для Android-телефона. Машина для Китая с магнитолой Baidu CarLife видит телефон как обычный CarLife, а на экране появляется Android Auto или свой рабочий стол с 2ГИС, Яндекс Навигатором и Алисой. Магнитолу не прошивают, нужен только телефон и USB-кабель. Проверено на 25 моделях Honda, Toyota, Mazda, VW, Skoda, Hyundai, Kia.

## Команды и шаги

```
Скачать APK: https://github.com/YegorkaPomidorka/headswap/releases (или сайт https://yegorkapomidorka.com/headswap/)
В Android Auto включи режим разработчика (10 тапов по «Версия»), затем ⋮ → «Вкл. сервер головного устр-ва». Один раз, мастер в приложении покажет где
Подключи телефон к магнитоле кабелем
```

Нужны Android 10 и новее и установленный Android Auto. Магнитола только с Baidu CarLife (2.0/2.1). Автомобильный Яндекс Навигатор работает только с Яндекс Плюс. «Свой лаунчер» после перезагрузки телефона надо активировать заново.

## Учти

Неофициальное приложение, на свой риск; Яндекс может закрыть лазейку в любой момент. Магнитолы, которые требуют шифрование CarLife, не заработают.
